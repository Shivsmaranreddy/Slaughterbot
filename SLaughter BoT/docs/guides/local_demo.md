# Local demo, when you choose to run it

No local app was launched for this file delivery. Follow README installation instructions later.
Start with loopback-only binding, fictional data and a manager token of at least 16 characters.
Visit /customer, create an inert-object demonstration order and retain its tracking token.
Visit /manager, enter the manager token, load records and update the order status. Refresh the
customer status to see the change. Create a batch, record output and waste, and test rejection
when their sum exceeds input. Add a task and an equipment maintenance record.

Request a model assessment before training: it must abstain. Inspect all four model statuses.
Arm the mock, move one step and stop it. Every subsequent movement request must be rejected
until explicitly rearmed. This only changes in-memory state and cannot move physical hardware.

Database is created on first app startup at output/deployment/demo.db. Preserve it if needed.
Do not use real customer data. Tracking tokens are bearer access secrets in this demonstration.
Manager authentication is a single local token, not production user/role management.
The server's schema initialization is version 1, not a production migration framework.
No Docker, GPU, paid service or cloud hosting is required for the untrained-model mock workflow.
