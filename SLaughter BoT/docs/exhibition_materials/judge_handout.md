# SLAUGHTER BOT: judge handout
Experimental assistance and management system, CBSE Science Exhibition 2026–27.

Demonstration: customer order workflow, MSME batch tracking, independently trained model interfaces
and a deterministic mock safety controller. Hardware scope: low-force positioning of inert objects only.

Models: visual CNN; aligned-volume autoencoder; learned scenario selection; robotic task policy.
Evidence: dataset manifests, held-out evaluations, policy baseline comparisons and export checksums.
Current status: source files supplied, models NOT TRAINED, runtime and hardware verification NOT RUN.

Limitations: images cannot certify food safety; synthetic volumes cannot validate anatomy; simulated
policies do not establish real-world reliability. Production enterprise features remain a roadmap.

Student contribution: explainable implementation, integration and independently reproducible experiments.
